## 贯穿的设计原则(各文档中反复出现)

1. **数据按性质分层**(10):状态(索引,LWW)/ 用户内容(blob,可靠)/ 派生缓存(可丢可再生)——往索引加东西前先过这三根轴
2. **哑远端约束下客户端执法**(09、11、12):WebDAV 不能裁决只能存取,一致性靠客户端记忆(基线、探测、断点)
3. **复用既有管线而非发明**(10、12):封面是"小号文件"就享受文件待遇;迁移是"字节搬运"就走 PUT/GET
4. **AEAD 认证兜底轻量校验**(01、12):错位/损坏必在读取时暴露,验证用 size + 抽查,不全量回读
