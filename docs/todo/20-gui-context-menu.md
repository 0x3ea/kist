# TODO-20 — GUI 右键菜单(文件操作收进 context menu)

> 状态:进行中(2026-08-30 用户反馈驱动)
> 来源:GUI 文件页右键弹出的是 webkit2gtk 原生菜单(后退/前进/停止/重新加载/检查元素)——纯网页行为,与"网盘管理器"的产品形态相悖

## 问题

- 右键是文件管理器最高频的操作入口,当前却是浏览器菜单;重命名/移动/删除/元数据只有工具栏按钮一条路
- webkit2gtk 的原生菜单不可裁剪(信号层定制要拿 WebKitWebView 句柄,Wails v2 不暴露),唯一现实路径是 JS 层 `contextmenu` `preventDefault` + 自绘菜单

## 语义定案

- **原生菜单全局抑制**:`document.addEventListener('contextmenu', preventDefault)` 挂 main.ts 一次,锁定页/设置页同样生效——用户点名的"后退/前进/停止/重新加载/检查元素"一处不留(输入框内的剪切/复制/粘贴原生项随之消失,接受;Ctrl+V 不受影响)
- **右键即选**:右键目标未在选区 → 清空两套选区、只选中它;已在选区 → 保持现有多选(配合勾选框可先多选再右键批量操作),与主流文件管理器一致
- **菜单条目固定四项**(文件/目录卡、列表行皆可呼出):
  - 重命名:仅单个目录可用(TODO-19 后端只支持目录;文件项禁用并注明"文件重命名尚未支持")
  - 移动:选中文件数 > 0 可用(`MoveFiles` 只支持文件;目录移动是 TODO-19 立项时明示的范围外)
  - 元数据:恰好一个条目(目录或文件)可用,复用 MetaDialog 双模式
  - 删除:任何选区可用,多项时文案带数量;危险样式
- **工具栏收敛**:重命名/移动/删除/元数据四按钮移除(操作全部收进右键),保留搜索/上传文件/上传文件夹/新建文件夹/下载/视图切换——下载不在本次四项之列,留工具栏
- **空白区右键**:只有抑制(无自定义菜单),不发明新入口

## 范围外存档

- 文件重命名(RenameFiles,后端 ~20 行)与目录移动(改 parent_id)——TODO-19 立项时已存档,后端落地前菜单里保持禁用态明示
- 右键菜单加"下载/打开"等更多条目:按需再议,本次不扩
- webkit2gtk 信号层菜单定制(Wails v3 或改绑定时再评估)

## 验收标准

- 任意页面右键不再出现后退/前进/停止/重新加载/检查元素
- 右键目录卡/文件卡/列表行:菜单四项按上述禁用规则出没;未选中目标时右键即选中它
- 先勾选多个文件再右键其一:移动/删除作用于整个选区
- 重命名弹 RenameDialog、移动弹 MoveDialog、元数据弹 MetaDialog、删除走确认——与原工具栏按钮行为逐项一致
- 工具栏只剩搜索/上传×2/新建文件夹/下载/视图切换
- 视口边缘呼出菜单不溢出(夹紧);Esc/点外部/滚动关闭
