# TODO-02 — 上传续传·轻量版:保留加密产物

> 状态:**已并入 [TODO-13](13-outbox-manual-upload.md)**(2026-08-20)
> 来源:PLAN.md 后续计划第 2 项

## 方案

上传失败时**不删已加密的临时文件**,重试跳过重新加密、直接重传整个密文文件。

- 收益:省本地加密时间(重试路径上唯一的重复劳动)
- 边界:通用 WebDAV 的 PUT 是整对象替换,协议上不存在部分写入——所以只省本地 CPU,不省网络流量
- 与 TODO-03 的关系:本项是其零成本前置;真实痛点出现前不值得上分块对象
